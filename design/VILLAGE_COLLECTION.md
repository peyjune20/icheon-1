# 한 장의 이천 마을 컬렉션 화면 설계

## 기존 배치의 문제

이전 시안은 동일한 크기의 여섯 잔디 구역에 테마별 조형물을 모았습니다.
테마 라벨과 경계가 먼저 보여 하나의 마을이 아니라 여섯 개 스티커 판처럼 읽혔습니다.
방문 수는 장소 단위였지만 공간 배치는 테마 단위라, 풍경이 하나씩 완성되는 느낌이 약했습니다.

## 새 레이아웃

논과 집, 연못, 냇가, 두 다리, 오솔길이 연결된 **한 장의 풍경**을 사용합니다.
테마별 구역/섬/격자와 지도 위 고정 제목을 없앴습니다.
30개 조형물은 정원, 길 가장자리, 냇가, 집 앞 등에 불규칙하게 분산하며, 역할 진행도는 그림 아래에 별도로 배치합니다.
한 장소의 스탬프를 찍거나 해제하면 정확히 그 ID의 조형물만 컬러/실루엣으로 바뀝니다.

| 레이어 | 구성 | 편집 위치 |

| 2 슬롯 | 장소별 바닥 기준 x/y, 크기, 스프라이트 선택. 테마와 독립적인 좌표 | src/features/tour-stamps/village-layout.ts |

배경 전체를 흑백으로 바꾸지 않습니다. 사각 배지/깃발을 조형물 대신 올리지 않습니다.
조형물 주변에 슬롯 테두리나 색깔 섬을 만들지 않습니다.

## 디자이너 편집 규격

- 원본 아트보드: 1586 × 992px. 화면 비율: 16:10, 현재 반올림 차이만큼 object-cover 크롭.
- 좌표 원점: 그림 왼쪽 위. x/y/width/height 모두 아트보드 대비 백분율.
- 앵커: 조형물의 **가운데 아래(발)**. CSS translate(-50%, -100%).
- 원본 좌표 환산: x(px)=1586×x/100, y(px)=992×y/100.
- 겹침 순서: zIndex=round(y). 앞쪽에 있는 조형물이 뒤쪽 위에 보임.
- 기존 village-sprites.png는 1254×1254 투명 스프라이트 시트. 역할별 row, 슬롯별 column으로 crop합니다. x 경계 [0,260,505,752,992,1254], y 경계 [0,219,425,622,829,1028,1254].
- 역할 row: 식당0 / 숲1 / 공원2 / 카페3 / 체험4 / 실내5.
- 스프라이트 변경 시 바닥선과 투명 여백을 유지합니다. 배경 이미지에 30개 스티커를 합성해 버리면 상태 전환이 불가능하므로 별도 레이어를 유지하세요.
- 상단 원경 슬롯은 작고 전경 슬롯은 크게 조절합니다. 같은 테마끼리 줄 세우지 않습니다.
- 별도 사용자 추가 장소는 이 기본 30개 수집 슬롯에 자동 삽입하지 않습니다. 기본 ID를 재사용하거나 변경하지 마세요.
- 영업 미확인/중단 장소는 기존 방문 기록 보존을 위해 수집판에 남아 있지만 자동 추천은 제외합니다.

## 인터랙션과 반응형

- 클릭/탭: 연결된 장소 상세 페이지.
- 마우스 hover/키보드 focus: 장소명 툴팁. aria-label은 장소명 + 미방문/색칠 완료.
- 방문 상태 전환: 500ms, reduced-motion이면 전환 애니메이션 없음.
- 모바일: 그림 최소 너비 900px, 프레임 안에서 가로 스크롤. 터치로 좌우 이동 안내 표시. 페이지 전체가 옆으로 늘어나지 않습니다.
- 지도 위 정보 과밀을 막기 위해 역할 통계는 그림 밖의 6개 작은 진행도 UI로 표시합니다.
- 기존 접이식 테마 스탬프북과 방문일/해제 UI는 유지합니다.

## 검수 기준

1. 0/30 상태: 배경은 컬러, 30개 조형물만 실루엣.
2. 특정 ID 한 곳 방문: 그 ID의 조형물 하나만 원래 컬러, 전체 및 해당 역할 수가 1 증가.
3. 같은 역할의 두 장소 방문: 한 영역 통째로 색칠되는 것이 아니라 각각의 조형물 두 개가 변경.
4. 스탬프 해제: 해당 조형물만 실루엣으로 복귀. 날짜 수정은 좌표/색에 영향 없음.
5. 30/30 상태: 풍경 속 모든 추가 조형물 컬러. 배경과 그림자/스프라이트가 서로 연결된 장면으로 보임.
6. 모바일 가로 스크롤/키보드 focus로 30개 슬롯 모두 접근.

자동 검증은 30개의 ID 일치/좌표 중복 없음/프레임 밖 슬롯 없음, 기존 스탬프 상태 변화를 확인합니다.
이번 브라우저에서는 30개 DOM 슬롯, 데스크톱 풍경, 모바일 가로 스크롤 레이아웃을 확인했습니다.

## 이미지 자산

새 배경은 builtin imagegen으로 생성한 상상 마을입니다. 실제 이천의 도로·건물·좌표를 나타내지 않습니다.
기존 투명 조형물 시트를 재사용해 현재 스탬프 상태/디자인 연결을 유지했습니다.
생성 요청은 연결된 한국 농촌, 따뜻한 수채화/과슈, 굽은 냇가와 두 다리, 연못, 논/집/오솔길, 자연스러운 여백을 지정했고 분리된 섬·6개 구역·격자·UI·텍스트를 금지했습니다.
