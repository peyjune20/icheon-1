- 별빛정원우주는 영업 중단 안내를 유지하여 자동 추천에서 제외합니다.
- 예스파크/사기막골은 단지 대표 주소, 라이스카페는 공원 내 위치입니다. 개별 입구를 임의로 확정하지 않습니다.

- Kakao 키가 설정되면 장소명/이천 지역/주소를 대조하여 좌표를 보강합니다. 검색 결과가 여러 지점으로 모호하면 첫 결과를 임의 선택하지 않습니다.
- 실제 30곳 Kakao 검색 및 좌표/진입로 검증은 키 설정 후 수행해야 합니다. 현재 확인된 좌표만 대체 지도 핀에 사용합니다.
